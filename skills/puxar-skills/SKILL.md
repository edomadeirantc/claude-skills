# Puxar skills

1. Escolhe as skills em ~/.cursor/skills que batem com o pedido
2. Le o SKILL.md de cada uma
3. Anuncia Usando [skill] para [objetivo]
4. So depois executa
5. Nao carregues as 257 todas
